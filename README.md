- Пайплайн: `SigLIP` → `FAISS` → reranker на `Qwen2-VL` + `LoRA`.
- Hit@1 реранкера: 60.7 → 73.5% (+12.8 пп) на переранжировании кандидатов.

- Деплой: `FastAPI` + `vLLM` + `Docker`, мониторинг через `Prometheus` + `Grafana`.
